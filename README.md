## 🌟 **About Mystiva Enchanted Hampers**

**Mystiva Enchanted Hampers** is a magical e-commerce platform that specializes in creating personalized gift hampers, each designed to tell a unique fairytale-like story. Our mission is to offer a delightful, dream-inspired experience through carefully curated hampers, tailored to suit every occasion and loved one.

With categories like *For Him*, *For Her*, *Parents*, *Periods*, *Flowers*, *Chocolates*, and more, Mystiva provides a wide range of options to ensure you find the perfect gift. You can customize hampers by selecting the products, box styles, and adding personalized notes, making each gift as special as the recipient.

## 🧰 **Tech Stack**

- **Frontend**: HTML5, CSS(Bootstrap), JavaScript  
- **Backend**: Node.js, Express.js 
- **Database**: MongoDB / MySQL 
- **Animations**: CSS transitions, JavaScript for sliding cards & interactivity  
- **Authentication**: Gmail Login + OTP validation
