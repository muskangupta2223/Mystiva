# 🧺 **Mystiva Enchanted Hampers**  
*A fairytale-themed e-commerce website for personalized gift hampers, where every gift tells a story.*
![Screenshot 2025-05-01 030352](https://github.com/user-attachments/assets/2f6f146a-4c73-488a-b2eb-5e296abde278)


---

## ✨ **Features**

- 🧚‍♀️ **Fairytale-inspired UI** with pastel tones and dreamy fonts  
- 🎁 **Custom hamper builder** with item selection, box styling, and personal notes  
- 🛍️ Categories like *For Him*, *For Her*, *Parents*, *Periods*, *Flowers*, *Chocolates*  
- 🛒 **Full cart & checkout system** with delivery scheduling and payment options  
- 🔍 **Product filters**, search bar, and **sliding offer cards**  
- 🌟 **User account system** with Gmail login, OTP verification & magical transitions  


---

## 🧰 **Tech Stack**

- **Frontend**: HTML5, CSS(Bootstrap), JavaScript  
- **Backend**: Node.js, Express.js 
- **Database**: MongoDB / MySQL 
- **Animations**: CSS transitions, JavaScript for sliding cards & interactivity  
- **Authentication**: Gmail Login + OTP validation
